# СверкаДел — плагин для Claude Code

СверкаДел (sverkadel.ru) — российский сервис проверки ссылок на судебную практику в юридических документах, написанных с помощью ИИ (ChatGPT, DeepSeek, Алиса, GigaChat и др.). Сверяет каждый номер дела с картотекой арбитражных судов: есть ли дело, совпадают ли суд и дата, не отменён ли акт. Проверяет также Пленумы ВС, постановления Президиума ВАС и обзоры ВС. 5 проверок в месяц бесплатно.

Плагин подключает к Claude Code MCP-сервер СверкаДел (`https://sverkadel.ru/mcp`, инструмент `verify_citations`) и навык «Проверка ссылок на практику» (`/sverkadel:proverka-ssylok`). Навык подсказывает Claude, когда проверять ссылки (вы попросили проверить документ или Claude сам написал юридический текст с номерами дел) и как читать результат.

Через MCP текст документа приходит на сервер, обрабатывается в памяти и не сохраняется. Если документ нельзя отправлять — проверяйте на сайте, там разбор идёт в браузере.

## Установка

1. Войдите на https://sverkadel.ru/account (вход по ссылке из письма) и выпустите API-ключ.
2. В сессии Claude Code:

   ```
   /plugin marketplace add bemuzir-maker/sverkadel-claude-plugin
   /plugin install sverkadel@sverkadel
   ```

3. Claude Code спросит API-ключ — вставьте ключ из `/account`. Ключ хранится в защищённом хранилище системы, а не в файлах настроек; плагин передаёт его в заголовке `X-API-Key`.

Проверить подключение: `/mcp` в сессии — сервер `sverkadel` должен быть в списке подключённых.

Сменить ключ (например, после перевыпуска в `/account`) или ввести его, если установка шла из терминала (`claude plugin install`): `/plugin configure sverkadel@sverkadel` в сессии или `/plugin` → вкладка **Installed** → `sverkadel` → **Configure options**.

## Claude Desktop, Cursor и другие клиенты

Плагин — только для Claude Code. Вставки для Claude Desktop, Cursor и `claude mcp add` с вашим ключом — на https://sverkadel.ru/mcp-info.

## Пример

> Проверь ссылки на практику в этом отзыве: «…как указано в постановлении Арбитражного суда Московского округа от 12.03.2024 по делу № А40-123456/2023…»

Claude вызовет `verify_citations` и вернёт по строке на ссылку:

- ✅ для дела — в силе: дело есть, суд и дата совпали, акт не отменён; для акта Президиума ВАС и обзора ВС — акт найден (в силе ли он, не проверяется);
- ⚠️ отменён или изменён — ссылаться нельзя без оговорки;
- 🔍 суд или дата не совпали, другое дело; при глубокой проверке — акт не о том;
- ❔ требует проверки — это не ошибка, проверьте вручную по ссылке на kad.arbitr.ru;
- ❌ не найдено — дела с таким номером нет в картотеке, ссылка, вероятно, выдумана.

## Лимиты

- Только арбитражные суды; суды общей юрисдикции не проверяются.
- До 50 ссылок за один вызов.
- Вызов со ссылками списывает одну проверку документа: 5 базовых проверок в месяц бесплатно, дальше — оплаченный документ (https://sverkadel.ru). Вызов без ссылок не списывается.
- Глубокая проверка (`deep=true`, сверка тезиса с текстом акта) всегда списывает оплаченный документ; навык включает её только после вашего согласия.

## Claude for Legal

В `anthropics/claude-for-legal` (CONTRIBUTING.md, README, CONNECTORS.md на 19.10.2026) отдельного приёма навыков сообщества нет: вклад — форк и pull request с подписью CLA, навыки добавляются внутрь существующих плагинов (`<plugin>/skills/<skill>/SKILL.md`) с прогоном `scripts/validate.py` и `scripts/lint-tool-scope.py`, а сообщественные навыки README отправляет в свои реестры и в `legal-builder-hub` (проверка и allowlist у пользователя). Для MCP-серверов есть путь подачи: PR в `.mcp.json` подходящего плагина с URL, способом авторизации (OAuth или API-ключ) и описанием; Anthropic тестирует на качество выдачи и устойчивость к инъекциям, прошедшие попадают в `.mcp.json` по умолчанию, остальные — в README плагина. Набор ориентирован на право США, требования к юрисдикции не названы. Вывод: подавать имеет смысл не навык, а коннектор `sverkadel` — PR в `.mcp.json` профильного плагина (например, `litigation-legal`) после публикации плагина и первых пользователей; реалистичный исход — упоминание в README плагина.
